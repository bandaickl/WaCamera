# GitHub公開先と更新方法

- ソースコード：https://github.com/bandaickl/WaCamera
- 配布ファイル：https://github.com/bandaickl/WaCamera/releases
- 不具合報告：https://github.com/bandaickl/WaCamera/issues

CurseForgeの「Source」欄にはソースコードのURLを設定します。「Issues」または不具合報告先の欄を使う場合は、上記の不具合報告URLを設定できます。

## 利用者がダウンロードするもの

Releasesの「Assets」にある、自分のMinecraftとローダーに合うJARを一つ使います。GitHubが自動生成する「Source code (zip)」「Source code (tar.gz)」は開発用ソースであり、modsフォルダーへ入れるファイルではありません。

**現在公開済みのReleaseはv1.0です。** この公開JARは音声ヘルパーEXEを同梱した旧版で、1.0.3の同梱解除は反映されていません。今回は1.0.3のソース更新とローカル配布物の準備までで、1.0.3のGitHub Releaseは作成しません。両版のassemble・ForgeのreobfJarとJAR内容の確認を終え、`dist/1.0.3/`に次のファイルを配置しました。将来公開する際は[1.0.3の変更履歴](release-1.0.3-changelog.md)の確認範囲を説明に残してください。

- `wacamera-forge-1.20.1-1.0.3.jar`
- `wacamera-neoforge-1.21.1-1.0.3.jar`
- `SHA256SUMS.txt`：JARのダウンロード内容を確認するためのハッシュ値。

1.0.3は音声ヘルパーの同梱・自動展開・更新をやめ、新規設定を無音にする変更です。等倍のゲーム音は別途用意したヘルパーの絶対パスを手動指定して利用します。旧版の設定・配置済みヘルパーは維持します。通常のMODビルドにC++ツールは不要です。利用者の希望によりMinecraft起動・自動テスト・音声テスト・実録画は行いません。回復データ削除とNeoForgeのIris 1.8.12＋Sodium 0.6.13連携は従来の範囲を維持し、NeoForgeのシェーダー映像・性能は未検証です。シェーダー有効＋Distant Horizons併用も引き続き未対応です。

## 今後の更新

開発フォルダーは引き続きこのWaCameraフォルダーを使います。ソースの更新は修正をコミットしてGitHubへpushします。今後、新しいバージョンを公開すると決めた場合に、そのタグとReleaseを作成して対応するJARを掲載します。今回のソース更新だけではタグやReleaseを作成しません。公開済みの1.0ファイルは、通常の修正では上書きせず、新しいバージョンを作ります。

ビルド方法はルートのREADMEを参照してください。GitHub Actionsのビルドは手動実行のみです。ソースのアップロードや更新だけではビルド・テストを起動しません。

## 公開対象

ソース、ビルド用スクリプト、説明文、正式ロゴ、MITライセンス、外部コンポーネントの案内を公開します。録画、セーブ、ローカル設定、開発キャッシュ、参考画像、認証情報はGitの管理対象から除外しています。

FFmpeg・ffprobe本体はこのリポジトリや配布JARに含めません。1.0.3では音声ヘルパーEXEもJARに含めず、ソースと任意のビルド手順だけを公開します。新たなヘルパーの外部配布や自動取得は設けません。既存のFFmpeg準備機能、各ツールとの連携方法、ライセンス情報は、ルートの`THIRD_PARTY.md`に記載しています。
